# Screenshots

Captured from a Galaxy Tab A9 (800×1340, Android 16) using the **debug build's demo session**: the cover art is generated by
`DemoSession.kt`, the tracks and artists are made up, and the device is named "Living room tablet". No copyrighted artwork and
no real listening history appear in any of them.

The debug build adds `DemoActivity` (debug source set only; release builds contain none of it). With a debug build installed and
media access granted:

```bash
adb shell am start -n app.perch/.DemoActivity --ei track 1 --ez playing true --el pos 78000
adb shell am start -n app.perch/.DemoActivity --ez stop true     # no session: the clock
```
